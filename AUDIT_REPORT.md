## 4. Pending Recommendations

### R1 — Restrict CORS Origins (HIGH)

**File:** `src/supabase/functions/server/index.tsx`  
**Current:** `app.use('*', cors())` — allows all origins  
**Recommendation:** Replace with an allowlist of known production domains:

```ts
app.use('*', cors({
  origin: ['https://your-production-domain.com'],
  allowMethods: ['GET', 'POST', 'PUT', 'DELETE', 'OPTIONS'],
}));
```

### R2 — Reduce Server-Side Logging of Sensitive Data (MEDIUM)

Several `console.error` / `console.warn` calls in the Edge Function log raw error objects and
request details. In production, use a structured logger that filters sensitive fields.

### R3 — Move Documentation from `src/` to `docs/` (LOW)

The `src/` directory contains 40+ markdown files (CHANGELOG, guides, setup instructions, etc.).
These should live under a `docs/` folder at the project root to keep source code clean.
This is a large refactor and should be done carefully to update any inter-document links.

### R4 — Update Dependencies with Known CVEs (MEDIUM)

Run `npm audit` to check for CVEs in current dependencies (jspdf, xlsx, etc.) and update
where safe to do so. Test thoroughly after any dependency upgrade.

### R5 — CI Workflow: Use Upload Artifact v4 (LOW)

`upload-artifact@v3` is deprecated. Update `.github/workflows/ci.yml` to use `actions/upload-artifact@v4`.
